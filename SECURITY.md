# Security

Found a vulnerability? Please don't open a public issue or PR for it.

Report it privately through [GitHub's Security Advisories](https://github.com/syaniclauncher/minecraft-lib-golang/security/advisories/new).

Include whatever helps reproduce it:
- A short description and potential impact.
- Steps to reproduce, proof of concept, or a minimal example.
- Affected versions or commits, if known.

I'll take a look and follow up there. Please give me a reasonable amount of time to investigate and prepare a fix before sharing it publicly.

Thanks.
